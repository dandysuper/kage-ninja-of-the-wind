# Page theme (Edit theme on your game page)

Images:

- Banner: upload `7-banner.png` (960×300, the width of the page column). It replaces the page title, so the KAGE logo is part of it.
- Background: upload `8-background.png` (2560×1440), then set Repeat: No repeat, Align: Center, and turn on Fixed.

Colors, all from the game's palette:

| Setting | Color |
| --- | --- |
| BG | `#0d0b14` (the background fades into this at its edges) |
| BG2 | `#25213b` |
| Text | `#f3e3c3` |
| Link | `#f4c94e` |
| Buttons | `#cc3340` |
| Headers | `#f4c94e` |

Optional: set the header font to Silkscreen (a Google Font) for pixel-style section titles and keep the default body font for readability.
